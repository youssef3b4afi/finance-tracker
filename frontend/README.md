# Finance Tracker — frontend

React + TypeScript single-page app built with Vite. See the [root README](../README.md) for the full project,
including how to start the database and backend this app talks to.

```bash
npm install
npm run dev     # dev server; proxies /api to the backend on http://localhost:8081
npm run lint    # ESLint
npm run build   # type-check with tsc, then production build into dist/
```
